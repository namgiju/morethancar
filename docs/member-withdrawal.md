# 회원 탈퇴 운영 메모 (STEP 10-impl-C, 카카오 계정 LATER-1)

정책 결정은 `docs/internal/MORETHANCAR_NEXT_TASKS.md`의 STEP 10과 §4 LATER-1에 있다. 이 문서는 운영에 필요한 설정과 절차만 적는다.

## WITHDRAWAL_HMAC_SECRET

- 탈퇴 후 재가입 제한(`withdrawal_blocks`)은 이메일·카카오 id·아이디의 원문을 저장하지 않는다. 이 키로 만든 HMAC-SHA256만 저장한다.
- 32자 이상의 난수를 쓴다. 예: `openssl rand -hex 32`. 채팅이나 커밋에 붙여 넣지 않는다.
- prod 오버레이(`docker-compose.prod.yml`)와 prod 프로파일은 이 값이 없으면 core를 기동하지 않는다.
- prod가 아닌 환경에서 비어 있으면 회원 탈퇴 요청을 503으로 거부한다. 이미 제한 행이 있는 DB라면 가입 확인도 503으로 막는다. 제한을 조용히 건너뛰지 않는다.

### 키 교체

기존 행은 이전 키로 만든 값이다. 키를 바꾸면 기존 행은 더 이상 일치하지 않아 모든 재가입 제한이 풀린다. 원문을 저장하지 않으므로 새 키로 다시 계산할 수도 없다.

1. 키가 유출된 경우가 아니면 교체하지 않는다.
2. 교체해야 하면 남은 제한 기간을 확인한다(읽기 전용):
   `SELECT reason, count(*), max(expires_at) FROM withdrawal_blocks WHERE expires_at IS NULL OR expires_at > NOW() GROUP BY reason;`
3. 기간 제한(COOLDOWN, 기한 있는 SANCTION)은 교체 후 풀린다는 점을 받아들이고 교체한다. 무기한 SANCTION(`expires_at IS NULL`)이 있다면, 해당 회원의 운영 기록(`admin_member_actions`, `moderation_logs`)을 남겨 두고 수동으로 관리한다.
4. 교체 후 이전 키로 만든 행은 E(정리 작업)에서 만료 행과 함께 지운다.

## 카카오 계정 탈퇴 (LATER-1)

비밀번호 대신 카카오 재인증으로 본인을 확인하고, 앱 연결을 끊은 뒤 탈퇴한다. 연결 끊기는 사용자 액세스 토큰으로 한다(`POST https://kapi.kakao.com/v1/user/unlink`). Admin 키는 쓰지 않고, 토큰은 저장하지 않는다. 새로 필요한 운영 설정이나 비밀값은 없다.

1. 내 차고의 탈퇴 창에서 동의하면 `POST /api/auth/kakao/withdraw`가 사전 검사(비밀값, 관리자·운영자 아님, 예약중 매물 0)를 한다. 통과하면 이 회원·세션에 묶인 5분 1회용 state를 발급하고 카카오 재로그인 주소(`prompt=login`)를 돌려준다.
2. 카카오에서 돌아오면 콜백(`/api/auth/kakao/callback`)이 차례로 확인한다: state의 용도와 시작한 세션이 맞는지, 사전 검사를 다시 통과하는지, 같은 카카오 회원번호인지. 그다음 연결을 끊는다. 카카오 HTTP 동안에는 DB 트랜잭션·잠금을 쥐지 않는다.
3. 연결을 끊은 뒤 짧은 트랜잭션에서 회원 행을 잠그고 모든 조건을 다시 검사한다. 통과하면 일반 탈퇴와 같은 처리를 한다. 재가입 제한에는 카카오 회원번호 HMAC이 들어간다.

결과는 브라우저 이동으로 알린다. 성공하면 `/`, 실패하면 `/home?kakaoWithdraw=<코드>`이고, 세션이 만료됐으면 `/login?...&kakaoWithdraw=SESSION_EXPIRED`다(연결을 이미 끊었으면 `UNLINKED_NOT_WITHDRAWN&reason=SESSION_EXPIRED`).

- 연결 끊기 전에 실패하면(취소, 다른 카카오 계정, 세션 불일치, 연결 끊기 실패) 아무것도 바뀌지 않는다.
- 연결은 끊겼는데 DB 단계가 거절되거나 실패하면(그 사이 예약중 매물·권한 변경, DB 오류 등) 계정은 그대로 남고 카카오 앱 연결만 끊긴다.
  - 사용자 안내: `UNLINKED_NOT_WITHDRAWN`. 다음 카카오 로그인 때 동의하면 다시 연결된다. 다시 시도하면 카카오 동의 화면이 한 번 더 나온 뒤 탈퇴된다(2026-11-03 결정).
  - 운영 기록: core WARN 로그 `Kakao unlinked but withdrawal not completed: user=<id> reason=<코드>`만 남긴다. 관리자 회원 처리 기록에는 남기지 않는다(2026-11-03 결정). 토큰과 카카오 회원번호 원문은 로그에 남기지 않는다.
  - 연결 끊기 응답을 받지 못한 경우(timeout)는 실제로는 끊겼을 수도 있지만 실패로 처리한다(`UNLINK_FAILED`, 계정 변경 없음). 이때도 다음 로그인·재시도는 같은 방식으로 동작한다.
- 확인할 로그(core): `Kakao unlink for withdrawal failed: user=<id> reason=<단계 HTTP 상태 코드>`. 허용된 오류 코드(KOE###, 카카오 API 숫자 코드)만 남긴다.
- 카카오 회원번호는 연결을 끊고 다시 이어도 유지된다. 카카오 문서와 FAQ 기준이고, 2018-09-19 이후 만든 앱이거나 콘솔의 [사용자 아이디 고정]이 켜진 경우다. 같은 카카오 계정의 재가입 제한은 이 전제에 기댄다. 실계정으로는 확인하지 않았다.

## 무기한 제한 해제

비활성화(DISABLED) 상태에서 탈퇴한 회원은 `expires_at IS NULL`인 SANCTION 행이 남는다. 지금은 관리자 화면이 없다. 해제하려면 운영자가 해당 `user_id`의 SANCTION 행을 직접 삭제한다. 이 작업은 관리자 기록 화면에 남지 않으므로 별도로 기록한다.

## 한계

- 이메일 없이 가입한 일반 계정은 아이디 HMAC만 남는다. 새 아이디로 다시 가입하는 것은 막을 수 없다.
- 카카오 계정은 비밀번호 탈퇴(`POST /api/auth/withdraw`)로는 탈퇴할 수 없다(`KAKAO_REAUTH_REQUIRED`). 위 카카오 재인증 경로만 쓴다.
- 카카오톡 인앱 브라우저에서는 `prompt=login`(재로그인 강제)이 제공되지 않는다(카카오 문서). 그 환경에서는 이미 로그인된 카카오 계정으로 바로 인증될 수 있다. 세션·state·회원번호 확인은 그대로 적용된다.
- 탈퇴로 지워진 공개 사진(프로필·차량·부품)은 이미 받은 브라우저·중간 캐시에 최대 1시간 남을 수 있다(MVP 단계 6 캐시 정책).
- 카카오 화면에서 5분 넘게 머물거나 다른 탭에서 카카오 로그인·탈퇴를 새로 시작하면 state가 맞지 않아 로그인과 같은 400 안내가 나온다. 아무것도 바뀌지 않았으므로 내 차고에서 다시 시작하면 된다.
- 탈퇴 재인증 화면에서 다른 카카오 계정으로 로그인하면 연결을 끊지 않고 중단한다(`KAKAO_MISMATCH`). 그 계정은 토큰 교환으로 앱에 연결된 채 남는다. 다른 회원의 계정일 수 있어 끊지 않는다.

## 실계정 확인 절차 (카카오 탈퇴, 운영 배포 2026-11-03 이후 미검증)

실제 회원 계정으로 하지 않는다. morethancar에 가입한 적 없는 **전용 테스트 카카오 계정**을 쓴다. 이 카카오 계정은 탈퇴 후 30일 동안 다시 가입할 수 없다.

1. 시크릿 창에서 morethancar.kr에 그 카카오 계정으로 로그인한다(새 회원이 만들어진다). 원하면 내 차고에서 차량·부품(사진 포함)·그 부품을 연결한 후기 글을 하나씩 만든다.
2. (선택) 실패 경로: 내 차고 → 회원 탈퇴 → 동의 → "카카오로 다시 인증하고 탈퇴" → 카카오 화면에서 취소한다. 기대 결과: 내 차고로 돌아와 "카카오 인증을 취소해 탈퇴하지 않았어요"가 나오고 그대로 로그인 상태다.
3. 다시 탈퇴 → 동의 → 버튼을 누른다. 기대 결과: 카카오 **로그인 화면이 다시** 나온다(prompt=login, 카카오톡 인앱 브라우저는 제외). 같은 테스트 계정으로 로그인한다.
4. 기대 결과: `/`로 이동하고 로그아웃 상태다. 카카오계정 설정 → 연결된 서비스 관리에서 morethancar가 없다. 1에서 만든 후기 글은 "탈퇴한 회원"으로 남고, 차량·부품 표시는 사라진다.
5. 같은 카카오 계정으로 다시 카카오 로그인한다. 기대 결과: 동의 화면 뒤 "탈퇴 후 30일 동안은 같은 정보로 가입할 수 없습니다." 이것으로 연결을 끊고 다시 이어도 회원번호가 같다는 것을 확인한다. 이 시도로 카카오 쪽 앱 연결이 다시 생기므로, 끝나면 카카오계정 설정에서 직접 연결을 끊는다.
6. 운영 확인(읽기만): 그 시각 core 로그에 `Kakao unlink for withdrawal failed`·`Kakao unlinked but withdrawal not completed`가 없어야 한다. 있으면 reason 코드를 기록한다.

결과(성공 여부, 확인 시각, 남은 이상)는 `docs/internal/MORETHANCAR_NEXT_TASKS.md` §4 LATER-1에 적는다.
