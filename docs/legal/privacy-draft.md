개인 운영자 남기주(이하 "운영자")는 morethancar(https://morethancar.kr, 이하 "서비스")를 운영하면서 「개인정보 보호법」에 따라 이용자의 개인정보를 처리합니다. morethancar는 개인이 운영하며, 특정 학교·기관·회사가 운영하는 서비스가 아닙니다.

## 1. 처리하는 개인정보 항목과 목적

### 가. 회원가입과 로그인

| 구분 | 항목 | 목적 |
|---|---|---|
| 일반 가입(필수) | 아이디, 비밀번호 | 회원 식별, 로그인 |
| 일반 가입(선택) | 이메일 | 비밀번호 재설정 메일 발송 |
| 카카오 로그인 | 카카오 회원번호, 카카오 닉네임 | 회원 식별, 로그인, 화면 표시 이름 |

- 비밀번호는 복원할 수 없는 방식(BCrypt)으로 바꿔 저장하며, 운영자도 원래 비밀번호를 알 수 없습니다.
- 카카오 로그인에서는 닉네임 제공만 요청합니다. 이메일·전화번호 등 다른 카카오 계정 정보는 받지 않습니다.

### 나. 서비스 이용 중 회원이 입력하는 정보

| 기능 | 항목 | 공개 범위 |
|---|---|---|
| 프로필 | 소개글, 프로필 사진, 커버 사진, 대표 차량 | 공개 |
| 내 차고 | 제조사, 모델, 연식, 트림, 색상, 변속기, 차량 별칭, 소개, 차량 사진 | 공개 |
| 내 차고 | **차량번호** | 본인과 운영진만 |
| 정비 기록 | 종류, 제목, 내용, 주행거리, 비용, 날짜 | 공개(공개 차량 페이지에 표시) |
| 차량 인증 | **자동차등록증 이미지** | 본인과 운영진만 |
| 커뮤니티 | 게시글, 댓글, 첨부 사진, 방명록 | 공개 |
| 커뮤니티 | 신고 사유 | 운영진만 |
| 부품장터(운영 보류) | 보류 전에 등록된 매물 정보, 사진, 지역, **연락처**(자유 입력) | 화면 접근 차단. 【미확정 — 매물 API는 아직 열려 있음, `open-items.md` C3】 |

- 자동차등록증에는 소유자의 이름, 주소, 생년월일 등이 들어 있을 수 있습니다. 차량 인증에 필요한 것은 차량번호와 차량 정보입니다. **이름·주소 등 그 밖의 개인정보는 가리고 올려 주세요.** 업로드 화면에도 같은 안내를 표시합니다. 【공개 전 화면 반영 필요, `open-items.md` C4】
- 게시물에 다른 사람의 개인정보를 올리지 마세요.

### 다. 서비스 이용 과정에서 자동으로 생성되는 정보

| 항목 | 목적 | 저장 위치 |
|---|---|---|
| 접속 IP 주소, 접속 일시, 요청 주소, 응답 결과, 브라우저 정보(User-Agent) 등 | 장애 대응, 부정 이용 방지 | 서버 접속 로그 |
| 로그인 세션 정보(회원 번호, 아이디, 권한) | 로그인 상태 유지 | 서버 세션 저장소(Redis) |
| 로그인 실패 횟수(아이디를 복원할 수 없게 바꾼 값) | 비밀번호 무차별 대입 방지 | 서버 세션 저장소(Redis) |
| IP 주소 또는 회원 번호별 요청 횟수 | 과도한 요청 제한 | 서버 메모리 |
| 좋아요, 북마크, 찜, 알림 | 서비스 기능 제공 | 데이터베이스 |

### 라. 이용자의 기기에만 저장되는 정보

- **최근 본 게시글·매물 목록**은 이용자 브라우저의 저장소(localStorage)에만 저장되고 서버로 보내지 않습니다. 브라우저 설정에서 지울 수 있습니다.
- **"내 주변 찾기" 위치 정보**는 이용자가 버튼을 누르고 브라우저 권한을 허용했을 때만 사용합니다. 서버에 저장하지 않습니다.

### 마. 운영 기록

| 항목 | 목적 |
|---|---|
| 운영진이 삭제한 게시글·댓글의 원문, 작성자 회원 번호와 아이디, 삭제 사유, 처리한 운영진 | 운영 조치의 근거 보관, 이의 제기 대응 |
| 회원 관리 조치 기록(정지·해제·탈퇴 등과 처리 일시) | 운영 이력 관리 |
| 이용 정지 종료일, 계정 상태 | 이용 제한 집행 |

## 2. 쿠키

- 서비스는 로그인 상태 유지를 위해 세션 쿠키 하나를 사용합니다. 이 쿠키는 스크립트에서 읽을 수 없게(HttpOnly) 설정되고, 운영 환경에서는 HTTPS로만 전송됩니다. 마지막 이용 후 30분이 지나면 만료됩니다.
- 광고·방문 분석용 쿠키는 사용하지 않습니다.
- 브라우저에서 쿠키를 차단할 수 있지만, 차단하면 로그인이 필요한 기능을 쓸 수 없습니다.
- 스팟 화면에서 지도를 표시할 때 이용자의 브라우저가 카카오 지도 서버에 직접 접속합니다. 이때 카카오가 처리하는 정보는 카카오의 개인정보 처리방침을 따릅니다.

## 3. 보유 기간과 파기

운영자는 아래에 적은 시점에 개인정보를 지우거나, 개인을 알아볼 수 없게 처리합니다. **현재 별도의 보관 기간이 정해지지 않은 항목은 그렇다고 적었습니다.**

| 항목 | 현재 처리 방식 |
|---|---|
| 로그인 세션 | 마지막 이용 후 30분이 지나면 자동 삭제. 로그아웃·탈퇴하면 즉시 삭제 |
| 비밀번호 재설정 링크 | 발급 후 10분이 지나거나 한 번 사용하면 삭제 |
| 로그인 실패 기록 | 15분 후 자동 삭제 |
| 요청 횟수 기록 | 서버 메모리에만 있으며 일정 시간 단위로 초기화 |
| 회원 정보(아이디·이메일·카카오 회원번호·닉네임·비밀번호) | 탈퇴할 때 즉시 삭제하거나 쓸 수 없는 값으로 바꿈. 회원 번호, 가입·탈퇴 일시, 계정 상태는 남음 |
| 차고, 프로필, 내 차고의 방명록, 좋아요·북마크·찜, 받은 알림 | 탈퇴할 때 즉시 삭제 |
| 게시물이 참조하지 않는 사진 | 탈퇴할 때 즉시 삭제 |
| 게시글·댓글, 다른 회원 차고에 쓴 방명록 | 탈퇴 후에도 남고 작성자는 "탈퇴한 회원"으로 표시. 별도 보관 기간 없음 |
| 회원이 직접 삭제한 게시글 | 공개 화면에서 바로 숨겨지지만, 신고 처리를 위해 원문이 데이터베이스에 남음. **현재 보관 기간과 자동 삭제 없음** 【미확정】 |
| 회원이 직접 삭제한 댓글 | 내용을 즉시 지우고 "삭제된 댓글입니다."로 바꿈 |
| 부품장터 매물(운영 보류 전 등록분) | 보류 후에도 삭제하지 않고 보관. **현재 보관 기간 없음** 【미확정】 |
| 판매중 매물 | 탈퇴할 때 비공개로 닫고 연락처와 찜을 삭제. 매물 내용과 사진은 비공개로 남음 |
| 판매완료 매물 | 탈퇴할 때 연락처만 삭제하고 거래 기록으로 남음 |
| **자동차등록증 이미지** | 심사가 끝난 뒤에도 남아 있음. 해당 차량을 삭제하거나 탈퇴할 때 삭제. 다시 인증을 신청해도 이전 이미지는 남음. **현재 보관 기간 설정 없음** 【미확정】 |
| **운영진 삭제 게시물 원문(운영 기록)** | 탈퇴하면 대상자 아이디만 "탈퇴한 회원#번호"로 바꾸고 원문은 남음. **현재 보관 기간과 삭제 기능 없음** 【미확정】 |
| 회원 관리 조치 기록 | 탈퇴 후에도 남음. **현재 보관 기간 설정 없음** 【미확정】 |
| 재가입 제한 정보(아래 설명) | 30일, 또는 제재 기간이 끝날 때까지 재가입 확인에 사용. **기간이 끝난 행을 자동으로 지우는 기능은 아직 없음** 【미확정】 |
| **서버 접속 로그** | 프록시 서버(nginx) 접속 로그가 컨테이너 로그로 남음. **현재 로그 보관 기간·순환 설정 없음** 【미확인 — 운영 서버 설정 확인 필요】 |
| 데이터베이스 백업 | 【미확인 — Neon의 복구용 이력 보관 기간】 |

**재가입 제한 정보**: 탈퇴한 회원의 아이디·이메일·카카오 회원번호는 원문을 저장하지 않습니다. 비밀키로 계산한 HMAC 값만 저장하여, 같은 정보로 다시 가입하려는지만 확인합니다. 원래 값으로 되돌릴 수 없습니다.

**파기 방법**: 데이터베이스와 저장소의 정보는 복구할 수 없도록 삭제 명령으로 지웁니다. 【미확인 — 외부 서비스의 백업·로그에 남은 사본의 삭제 시점】

## 4. 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 따라 수사기관 등이 적법한 절차로 요청하는 경우는 예외입니다.

서비스 운영을 위해 다음 외부 서비스를 사용합니다.

| 서비스 | 하는 일 | 처리되는 정보 | 데이터 위치 |
|---|---|---|---|
| Neon (PostgreSQL) | 데이터베이스 호스팅 | 데이터베이스에 저장되는 모든 정보 | 【미확인 — 프로젝트 리전】 |

## 7. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보에 대해 열람, 정정, 삭제, 처리 정지를 요구할 수 있습니다.

- **직접 할 수 있는 것**: 프로필 수정, 차량·정비 기록 수정과 삭제, 게시글·댓글 수정과 삭제, 매물 수정과 삭제, 일반 계정 탈퇴
- **이메일로 요청해야 하는 것**: 이메일·닉네임 변경(현재 회원이 직접 바꾸는 화면 없음), 그 밖의 열람·삭제 요청
- **카카오 계정 탈퇴**: 직접 탈퇴 기능은 준비 중입니다. 그 전까지는 이메일로 요청하고, 운영자가 보낸 확인 문구를 카카오로 로그인해 프로필 소개글에 입력하는 방식으로 본인을 확인한 뒤 처리합니다. 자세한 절차는 이용약관 제11조 3항을 따릅니다.
- 요청은 아래 개인정보 보호책임자 연락처로 보내 주세요. 운영자는 본인 확인 후 관련 법령이 정한 기간 안에 처리합니다.
- 법령에 따라 보관해야 하는 정보나 다른 사람의 권리와 관련된 정보는 요청을 제한할 수 있으며, 이 경우 이유를 알려 드립니다.

## 8. 안전성 확보 조치

- 비밀번호는 BCrypt로 바꿔 저장합니다.
- 운영 환경의 모든 접속은 HTTPS로 암호화합니다.
- 자동차등록증 이미지와 차량번호는 본인과 운영진만 볼 수 있게 접근을 제한합니다.
- 운영진 권한은 필요한 회원에게만 부여하고, 운영 조치는 기록으로 남깁니다.
- 로그인 실패 제한과 요청 횟수 제한으로 무차별 대입과 비정상적인 접근을 막습니다.
- 재가입 제한에는 원문 대신 HMAC 값을 저장합니다.
