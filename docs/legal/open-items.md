## A. 읽기 전용으로 확인할 수 있는 인프라 설정

저장소(확인 완료):
- `docker-compose.prod.yml`에 `logging` 설정이 없음 → Docker 기본 드라이버를 쓰며 로그 순환 설정이 없음
- nginx `access_log`는 기본값(`/health`만 끔). 기본 형식에는 IP, 시각, 요청, 상태, Referer, User-Agent가 들어감
- 로컬 `.env`에는 `DB_HOST` 값이 없어 Neon 리전을 알 수 없음. `SMTP_HOST=smtp.gmail.com`
- 운영 서버 주소가 AWS 서울 리전 대역으로 보임(추정. 콘솔에서 확정 필요)

운영 서버에서 승인받은 뒤 읽기 전용으로 확인할 것(값·비밀은 출력하지 않음):
- `docker info --format '{{.LoggingDriver}}'`, 컨테이너별 `docker inspect --format '{{.HostConfig.LogConfig}}'`
- 컨테이너 로그 파일 크기(`du`)로 실제 보관량 확인
- 운영 `.env`의 `DB_HOST`에서 리전 부분만 추출(`*.<region>.aws.neon.tech`)
